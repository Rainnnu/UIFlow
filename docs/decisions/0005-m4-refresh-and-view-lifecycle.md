# ADR-0005：M4 刷新会话与视图生命周期

- 状态：接受，新增 UI 的人工验收待确认。
- 日期：2026-11-19
- 范围：保存刷新、失效导航、异步请求作废、视图复杂度和失败恢复。不扩展 V2/V3，不改变 IR schemaVersion 1。
- 会话：每张目标图使用 GraphSession。递增 revision 控制结果发布；刷新/编辑/销毁立即撤销旧导航，只有最新 revision 能发布成功或失败。过期分析结果的导航服务也会失效。
- 保存策略：通过已读取的依赖列表监听文档保存、磁盘变化、删除和改名；180ms 合并连续保存。文本编辑只使快照失效，不逐字符重建。未被读取到的新文件可手动刷新入口来发现，不做全工作区扫描。
- 定位：NavigationService 使用 epoch，在异步打开编辑器前后检查是否被撤销；原文件/文档版本/内容摘要/真实路径校验继续保留。UI 失效时移除旧源码动作，直到新图加载成功。
- 根组件：首次按文件/光标选择后保留根组件名；刷新不再用陈旧 offset 选另一个组件。改名或删除时显示空图与诊断，重新执行打开命令建立新上下文。
- 消息：revision 为独立视图协议字段，未进入领域 IR。Webview 只接受不早于当前 revision 的图事件；运行时检查图结构和父级循环，异常数据展示错误，React 错误边界提供重载入口。
- 视图：默认展开当前组件和一层组件；更深层折叠，map 保持单一 ×N 模板。搜索和仅追踪路径保留祖先以维持同画布嵌套，过滤不增加/改写语义边。搜索可临时展开匹配祖先，清除后恢复折叠状态。全部展开与已有局部展开并存。
- 选择/布局：快照内 ID 相同的选择可保留；offset 变化时安全清空，不承诺跨编辑稳定 ID。刷新重新布局；拖动状态管理沿用前轮修复，不持久化布局。
- 主题：使用 VS Code CSS 变量、主题 class 与高对比边框；工具栏可换行，画布使用剩余高度。尚需深浅/高对比主题实机视觉验收。
- 工具链：完整依赖审计发现旧 Vite/Vitest 及传递依赖公告，最终锁定 Vite 6.4.5、Vitest 4.1.12，pnpm override 统一 Vite。两者支持本机 Node 22.12.0；TypeScript 5.8.3 不变。6.4.4 存在特定安全回归，已继续升级至 6.4.5。最终完整 audit 为零条公告。
- 验证：会话乱序/取消/恢复测试、异步导航中途撤销、视图筛选/非法图/根选择回归；真实 Extension Host 使用独立临时源码副本验证 Props 保存变化、变量删除、空图和失败恢复。测试写入限 .test-output，不改 demo 或业务代码。
- 发布边界：本轮完成开发宿主检查与审计，未打包 VSIX、安装测试或上传 Marketplace；不能把当前结果宣传为已发布正式版本。
