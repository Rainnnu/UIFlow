# ADR-0007：依赖布局与避障连线

- 日期：2026-11-20；状态：接受。
- 不改变 IR、源码证据或包含语义。局部数据节点按确定数据依赖分层，回调不参与 DAG；循环安全停止。回调节点放在数据节点之后，避免打断正向链。
- 使用渲染层正交可见网格，避开数据卡片和容器标题；对已占用线段增加代价，让独立边优先分流。端口短线允许共享，线条交叉处保留背景描边，回调保持橙色虚线与语义标签。
- 搜索只布局可见语义图，折叠收紧容器，同级容器并排；切换视图适配缩放。显式拖动坐标继续保留，自动坐标可随布局更新。
- 统一主题色、边框与工具栏；通用 in/out 文字在悬停、选中、键盘聚焦时显示，保留端口按钮及无障碍名称。
- 限制：不是全局最优无交叉布线；用户把节点拖到互相覆盖时可能无可行通道，保持真实端点并在节点下方绘制。大型图的交互性能仍需进一步实测。
