# ADR-0002：固定演示源码定位与快照校验

- 状态：接受
- 日期：2026-11-19
- 背景：M0 用户已确认路径高亮、折叠和详情正常；M1 将固定图关联真实源码，不引入 AST 分析。
- 映射：宿主读取 apps/demo-react/src 四个文件，通过显式且唯一的固定锚点建立 0-based SourceRef。缺失或重复锚点报错，不猜测位置。该机制仅用于内置固定示例，不能推广为符号分析器。
- IR：沿用 schemaVersion 1，填充现有 sourceRefs、definitionId 和 definitions；不新增领域字段。手工语义关系继续 partial，即使源码范围有效也不升为 confirmed。
- 定义/使用：组件分别注册 definition 和 usage；状态与变量注册 declaration，数据边注册 expression 或 binding。缺少来源的演示端口不提供定位按钮。
- 消息：UI 的 SourceActions 是独立视图元数据；只传随机 sourceRefId，不接受 URI 或行列。宿主校验消息字段与长度；未知及过期 ID 拒绝。
- 安全：创建映射及每次定位都通过 realpath 校验 demo 和工作区边界，避免通过符号链接跳到工作区外。校验内存文本摘要、同一文档对象的版本及磁盘内容摘要。删除、改名、编辑或磁盘变化使旧定位失败。
- 并发：重新加载建立全新服务与注册表；旧请求不能覆盖新图。重载期间无导航服务，旧 ID 不再有效。UI 忽略过期请求响应。
- 交互：选中后在详情显示有效定位按钮和位置，组件定义/使用分开；打开相邻编辑器并选中源码范围。错误就地显示，可重新加载演示恢复。
- 范围：本轮只实现固定示例导航、手动重载，不实现保存刷新、跨文件分析或业务源码修改。
- 验证：Vitest 验证安全边界；本机 VS Code Extension Development Host 中实际检查五种源码选区与无脏文档、过期 ID 拒绝；点击 UI 按钮的完整人工闭环仍需复核。
